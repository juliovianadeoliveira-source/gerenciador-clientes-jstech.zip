# JS Tech — Controle de Clientes

Painel particular com login para registrar clientes, acompanhar vencimentos e enviar mensagens de ativação, renovação e cobrança pelo WhatsApp. Os dados ficam sincronizados em um banco Supabase protegido por regras de acesso.

## Publicação no GitHub Pages

Publique os arquivos da pasta `dist` na raiz do repositório e configure o GitHub Pages para usar a branch `main`. Use **Fazer backup** regularmente para manter uma cópia adicional dos dados.
